Part 3: Preparing the Income Data

1. First, we need to do a few things to this .csv file in order for it to work. This requires some Excel manipulation of the data. We have to make sure that this Excel file and the shapefile with Michigan counties can talk to each other. For that, we will associated the GEO_ID column in the Excel file with an identifier in the shapefile. First, let's go ahead and remove the second column in the Excel file. This is extra information can be make our process break. For this, right-click on row number and select Delete.



2. Next, we only need the last three digits of the GEO_ID column. We are going to use Excel functions to select only those last three digits automatically for all 83 rows in this table. For this, first insert an empty column by right-clicking on the B column name and then selecting Insert.



3. At the top of the column, add the name "GEO_ID2".



4. Name, use the function =RIGHT() to select the first digits of all rows in the GEO_ID column. For this, type "=RIGHT(A2, 3)" in the cell under GEO_ID2 and press Enter. This function goes to cell A2 (column A, row 2), reads its value, and returns the three characters counted from the right. The value 001 should appear.



5. Select the cell that you just filled with the function (the one with 001). See the little green square in the bottom right corner of that cell? Double-click it. This will apply the function for all the cells below while making sure that they take the respective value of GEO_ID as it moves down. If you did this correctly, the column will populate with odd numbers from 001 to 165.



6. Select the whole GEO_ID2 column by clicking on the column name (should B). Then, change the input format to Text. This makes sure that in ArcGIS Pro we compare text to text, instead of text to numbers. ArcGIS Pro prefers to compare apples to apples and not apples to oranges.



7. Now, let's make sure to save this table as an Excel file. Currently, the table is saved as a .csv file, which does not preserve the Text formatting we applied in the previous step. For this, go to the File ribbon and click Save As. Make sure you are selecting Save As and not the plain Save option, otherwise, you will maintain the .csv format and lose your progress. Save the file in your lab folder and call it IncomeData. Make sure you save it as an Excel Workbook (.xlsx) or you will lose your progress.



8. Answer Part 3 Questions in the handout.
